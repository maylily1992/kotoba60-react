# Kotoba60 · 60 天日常日语对话地图

粉白、轻量、内容优先的日语日常对话 App。目标不是“看完”，而是把真实场景里的表达练到能直接开口。

## 内容结构

- 60 天全部完成，共计 6,476 条独立表达；第 02–60 天每天 108 条，第 01 天 104 条。
- 每天围绕一个完整旅行或生活场景，覆盖开场、需求、确认、回应、限制、故障、协商、修复和收尾等交流功能。
- 每张卡默认显示日语、完整平假名和中文；长句自动换行。点开可看说话者、场景、交流功能、语法定位、为什么这样说与语料来源。
- 句子分为“场景核心”“同场景扩展”“迁移补充”，可以先学最关键的句子，再扩展表达边界。
- 每天有独立的“今日总结”：词汇、九句场景锚点、详细语法系统、60 分钟练习路线和迁移任务。
- 句子卡可一键收藏，收藏内容保存在本机，可随时进入独立收藏页复习。
- 可标记“这句说顺了”，记录真实开口进度，不做自动打卡。
- 场景覆盖落地、交通、餐饮、购物、酒店、社交、身体不适、遗失、支付与网络故障、观光和回程。

## 目标与边界

60 天的目标是建立可控旅行与日常场景中的 A2 生存口语：能完成常见事务、维持多轮简单交流、在没听懂时主动修复。

课程不会承诺“涵盖所有日常对话”或“保证流利”。语言使用无限开放，60 天的价值是建立高频场景骨架、修复交流的能力和迁移能力，而不是穷尽所有句子。

## 内容来源与许可

- 第 01 天：Kotoba60 人工编排原创场景。
- 第 02–60 天：以 [Tatoeba](https://tatoeba.org/) 的日语—中文直接句对和日语—英语—中文桥梁句对为基础，经场景筛选、近似去重、人工场景核心补充和逐句假名重建。中文统一转换为简体显示。
- Tatoeba 语料许可：[CC BY 2.0 FR](https://creativecommons.org/licenses/by/2.0/fr/)。
- 逐词释义使用 [Trilingual Dictionary](https://github.com/Chiarandini/trilingual-dict) 的离线词典数据作为构建来源，其数据派生自 JMdict、KANJIDIC2（CC BY-SA 3.0）和 CC-CEDICT（CC BY-SA 4.0）；生成的逐词释义数据按相同分享方式标注。

## 运行

```bash
npm install
npm test
npm run dev
```

构建：

```bash
npm run build
```

第 02–60 天的数据是构建时生成的静态文件，运行 App 不需要 Python、模型 API 或额外服务。课程构建脚本位于工作区的 `work/build_curated_days.py`。
