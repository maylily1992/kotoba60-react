# Kotoba60 · 和ハル说一句

一个原创作风动漫少年「ハル」陪伴的日语日常口语学习 App。每天围绕一个明确意图，学习三种不同“温度”的说法，并通过语境判断、跟读、语法对照和开口练习真正会用。

## 每天 60 分钟

| 时间 | 内容 |
|---|---|
| 8 分钟 | 听同一意图的三种表达 |
| 10 分钟 | 六句完整对话跟读 |
| 10 分钟 | 语法对比、词语和动词形态 |
| 12 分钟 | 三轮社会关系情境选择 |
| 12 分钟 | 长按说话、确认转写、评分 |
| 5 分钟 | 换人物、换压力条件重说 |
| 3 分钟 | 总结与收藏 |

## 核心教学法：三温度

- **稳稳说**：第一次与服务人员、陌生人交流，信息完整、语体安全。
- **暖暖接**：先回应对方的信息或情绪，让对话有人味。
- **往前推**：补追问、确认或行动，让交流继续。

每天不是背孤立句子，而是判断“关系、场合、目的”，再选择适合的说法。

## 已实现

- 56 个独立日常场景，每天自动切换，也可主动换场景。
- 每个场景包含 3 个核心说法、6 句完整对话、6 个词语、6 句系统语法对照、3 个动词的变形与例句。
- 所有日语均附平假名；所有核心句和扩展句均有独立音频。
- 951 条预生成音频，统一为原创年轻动漫少年声线，不复制具体声优或已有角色。
- 长按说话、松开结束；识别结果支持候选选择、错字修改、文字兜底。
- 麦克风诊断、权限提示和单麦克风识别，避免录音器与语音识别冲突。
- “我们的话”收藏真正说出口的句子，保存在本机。
- 每日地方语气卡：大阪、京都、北海道、福冈、冲绳等地道表达与使用警告。

## 边界

Web Speech 只提供语音转写，不提供音素级发音诊断。评分综合日文、假名转写、反应时间与录音时长，页面不会把它冒充成专业发音考试。
