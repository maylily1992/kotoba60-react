# Kotoba60 · 60天6000句

粉白、轻量、内容优先的日语日常句子卡 App。

## 内容结构

- 60 天，每天 100 张句子卡，共 6000 张。
- 每天以 5 个场景词 × 20 种表达功能交叉组成。
- 每张卡可直接扫日语和中文；点开后可看完整假名、使用原因、核心词、语法功能和关联说法。
- 每天有独立的“今日总结”：10 个场景词、10 个功能句型、关联语法地图。
- 句子卡可一键收藏，收藏内容保存在本机，可随时进入独立收藏页复习。
- 场景覆盖落地、交通、餐饮、购物、酒店、社交、身体不适、遗失、问路、观光和最终旅行链。

## 目标与边界

60 天的目标是建立可控旅行与日常场景中的 A2 生存口语：能完成常见事务、维持多轮简单交流、在没听懂时主动修复。

课程不会承诺“涵盖所有日常对话”或“保证流利”。语言使用无限开放，60 天的价值是建立高频场景骨架和迁移能力，而不是穷尽所有句子。

## 运行

```bash
npm install
npm test
npm run dev
```

构建：

```bash
npm run build
```

## 说明

句子卡按场景词和功能句型系统交叉生成，用于高频句型迁移训练。每张卡都标注使用条件与语法关系；收藏后可以集中复习。
